# rs-helm

[![Generate Helm documentation](https://github.com/RS-PYTHON/rs-helm/actions/workflows/doc-helm.yaml/badge.svg)](https://github.com/RS-PYTHON/rs-helm/actions/workflows/doc-helm.yaml)
[![Publish Helm charts](https://github.com/RS-PYTHON/rs-helm/actions/workflows/publish-helm.yml/badge.svg)](https://github.com/RS-PYTHON/rs-helm/actions/workflows/publish-helm.yml)

[Helm](https://helm.sh/) charts of the services of [RS-Python](https://github.com/RS-PYTHON/rs-documentation),
to deploy them on [Kubernetes](https://kubernetes.io/).

## Overview

| Chart | Description |
|---|---|
| [rs-server-adgs](charts/rs-server-adgs/README.md) | STAC access to the AUXIP (ADGS) stations, that provide the Sentinel auxiliary files, see [External data sources](https://github.com/RS-PYTHON/rs-server/blob/develop/docs/doc/users/external-data-sources.md). |
| [rs-server-cadip](charts/rs-server-cadip/README.md) | STAC access to the CADIP stations, that provide the raw data (CADU) sessions of the Sentinel satellites. |
| [rs-server-prip](charts/rs-server-prip/README.md) | STAC access to the PRIP stations, that provide the Sentinel products. |
| [rs-server-catalog](charts/rs-server-catalog/README.md) | The [STAC](https://stacspec.org/) catalog of the products, based on [stac-fastapi-pgstac](https://github.com/stac-utils/stac-fastapi-pgstac), see [Catalog](https://github.com/RS-PYTHON/rs-server/blob/develop/docs/doc/users/catalog.md). |
| [rs-server-staging](charts/rs-server-staging/README.md) | The [OGC API - Processes](https://ogcapi.ogc.org/processes/) service that copies the products from the external data sources into the catalog, see [Staging](https://github.com/RS-PYTHON/rs-server/blob/develop/docs/doc/users/staging.md). It runs the transfers on a Dask cluster, with a JupyterHub API token (`dask.jupyterhub_api_token`). |
| [rs-server-frontend](charts/rs-server-frontend/README.md) | The home page and the aggregated OpenAPI documentation (Swagger UI) of the services. |
| [rs-server-osam](charts/rs-server-osam/README.md) | The Object Storage Access Manager, that creates the object storage accounts and rights of the users from their Keycloak roles, see [OSAM](https://github.com/RS-PYTHON/rs-server/blob/develop/docs/doc/users/osam.md). |
| [rs-dpr-service](charts/rs-dpr-service/README.md) | The [OGC API - Processes](https://ogcapi.ogc.org/processes/) service that runs the DPR processors on Dask clusters, see [rs-dpr-service](https://github.com/RS-PYTHON/rs-dpr-service). |
| [rs-server-station-secrets](charts/rs-server-station-secrets/README.md) | The URLs and credentials of the external stations. |
| [rs-catalog-staging-configmap](charts/rs-catalog-staging-configmap/README.md) | The bucket configuration of the catalog and of the staging (bucket and expiration delay per owner, collection and product type). |
| [stac-browser](charts/stac-browser/README.md) | The [STAC Browser](https://github.com/radiantearth/stac-browser) web interface, deployed once per service. The ingress path is forced to `/` because of [stac-browser#479](https://github.com/radiantearth/stac-browser/issues/479). |
| [mockup-station-adgs](charts/mockup-station-adgs/README.md), [mockup-station-cadip](charts/mockup-station-cadip/README.md), [mockup-station-lta](charts/mockup-station-lta/README.md), [mockup-station-prip](charts/mockup-station-prip/README.md) | The station mockups of [rs-testmeans](https://github.com/RS-PYTHON/rs-testmeans), for the test platforms. |

The README of each chart, with the description of all its values, is generated by
[helm-docs](https://github.com/norwoodj/helm-docs) from the comments of its `values.yaml` file: don't edit it by
hand.

## Getting started

On an RS-Python platform, the charts are deployed by
[rs-server-deployment](https://github.com/RS-PYTHON/rs-server-deployment), with the values of your inventory, see
[Deploy RS-Python](https://github.com/RS-PYTHON/rs-documentation/blob/develop/docs/administration/deploy.md).

The charts can also be used directly with Helm:

```shell
helm repo add rs-python https://rs-python.github.io/rs-helm
helm repo update rs-python
helm search repo rs-python --versions --devel

# Install a chart with some values
helm install rs-server-frontend rs-python/rs-server-frontend --namespace processing --set image.version=latest

# Upgrade a chart, reusing the previous values
helm upgrade rs-server-cadip rs-python/rs-server-cadip --namespace processing --reuse-values --set image.version=<version>
```

The charts are published on each release, with the version of rs-server (`appVersion`).
